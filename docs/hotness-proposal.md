# 熱門排序提案（尚未啟用）

現有排序仍按所選範圍的清單數排序，每人清單皆算一筆；同行合併只減少顯示列數。

## 分開「展示範圍」與「評分範圍」

建議固定使用最後日期以前的 7 個已結束日。最後日期若為今天，評分截至昨天；若為歷史日，則包含該日。改變展示天數不改變同一鳥點的分數，改變最後日期則會改變。可另提供「範圍內紀錄數」排序。

只顯示展示範圍內出現的鳥點時，改天數會改變候選名單，但共同鳥點彼此的熱門排序不變。UI 要明確標示評分截至日期，避免將固定分數誤認為所選範圍總分。

不用載入 7 天全部清單：建置時由已保存的逐日資料產生精簡摘要，按日期／縣市／鳥點保存清單數、不同顯示名稱數、資料品質。前端只載入摘要及展示範圍的清單。只在需要跨日合併人員時才需要名稱；本提案每日各自去重，不必在摘要保存名稱。

## 初版公式供討論

每天以鳥友顯示名稱去重，同人同地當天多次只算一人。這是名稱數的近似值，不是可驗證的實際人數；同名會低估，改名會影響比較，缺名稱不能算成多位。

- U：每日不同名稱數。N = max(U − 1, 0)，只一人反覆紀錄不產生群聚分。
- 最近三個已結束日，由新到舊加權：W = 0.5 N₁ + 0.3 N₂ + 0.2 N₃。
- C：截至評分日，連續至少兩人到訪的天數，上限三天。
- 持續係數 S = 0.5 + 0.5 C / 3。
- 降溫係數 D = min(1, (U₁ + 1) / ((U₂ + U₃) / 2 + 1))。
- 暫定分數 H = W × S × D。不是百分比，也不是特殊鳥種存在機率；權重尚待實際資料校準。

範例（日期由舊到新）：

| 三日不同名稱數 | 暫定分數 | 解讀 |
| --- | ---: | --- |
| 1 → 1 → 1 | 0 | 一人持續紀錄 |
| 0 → 0 → 8 | 2.33 | 單日聚集，待看是否持續 |
| 6 → 7 → 8 | 6.30 | 多人持續到訪 |
| 12 → 10 → 2 | 1.35 | 昨天明顯降溫 |
| 12 → 10 → 0 | 0.20 | 最近已無到訪紀錄，快速降序 |

最近三日之前的四日，可作為「較平常升溫」的基準，另顯示近期人數與基準差異。暫不將倍數直接乘進分數，避免 0 → 2 人因低基準而超越大量持續到訪。更多歷史後可延伸至 14／28 日，處理週末與本來就熱門的景點。

## 曲線與資料品質

展開鳥點顯示每日不同名稱數曲線，輔以清單數。今天使用空心點／虛線，不參與評分；今日累計上升仍可讓使用者看到。

缺日用斷線，不能補零。縣市達 200 筆上限時，鳥點的觀測值只能是下限，未出現不能視為零，不應據此判定退燒。需要的日子不完整時標為「資料不足／暫估」，不與有完整窗口的分數當成同等可信。即使未達上限，晚登、天候、週末與出遊安排仍可能影響人數；曲線無法證明特殊鳥種已離開。

回抓四天可修正最近趨勢；保存的較早歷史可用作基準，但較晚補登不會自動補入。摘要需隨回抓重建，不能沿用已變動日期的舊統計。
